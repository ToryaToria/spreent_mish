# Техническое задание

## Обязательные задачи проекта

Минимальный набор задач, которые необходимо реализовать.

### 1. Весь макет свёрстан

Макет должен быть свёрстан в двух состояниях, отрисованных в макете (десктоп и мобильная версия) в соответствии с критерием «CTS. Pixel Perfect».
Проверка будет проводиться на мобильной версии (480px) и на десктопе (1440px).
Все блоки проекта — обязательные для вёрстки. Границы и нейминг блоков отмечены в макете.
Все иные фичи будут поощряться дополнительными баллами и описаны в дополнительной части технического задания.

Примечание. В макете не представлен стайлгайд, но все состояния должны быть реализованы в соответствии с критерием «CTS-TEST-07. Состояние элементов соответствует стайлгайду». Состояния реализуются на усмотрение участника.

### 2. Резиновость вёрстки между мобильной версией (480px) и десктопом (1440px)

Вёрстка не должна ломаться на промежуточных разрешениях между мобильной версией (480px) и десктопом (1440px).

Сложная реализация резины на промежуточных разрешениях может учитываться жюри при выставлении финальной оценки и даёт возможность заработать дополнительные баллы.

### 3. Раскрывающееся меню в мобильной версии (480px)

Мобильное меню должно раскрываться при клике на бургер. Pixel Perfect для содержимого выпадашки меню проверяться не будет.

### 4. Форма в блоке «Footer»

Необходимо реализовать базовую валидацию данных в форме:

- Нельзя отправить пустую форму.
- Все поля обязательны для заполнения.
- Если email введён неправильно (например, без «@» или точки), форма не отправляется.
- После отправки данные уходят на адрес: http://echo.htmlacademy.ru/.
